# Horizon Rush

A mobile-browser 3D racing prototype designed for GitHub Pages.

## Deploy with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` to the repository root.
3. Open Settings → Pages.
4. Set Source to GitHub Actions or Deploy from a branch, using the `main` branch and `/ (root)`.
5. Open the generated Pages URL on your phone.

## Controls
- Touch: on-screen buttons
- Keyboard: WASD / Arrow keys
- Controller: standard gamepad axes
